# barge-monitor
Weather monitoring on a cyclic excursion: a system and architecture
demonstrator that runs whole in one browser tab (SRD Version 3.2).

**Demonstrator:** https://deepbluecltd.github.io/barge-monitor/demo/ ·
**Requirements:** https://deepbluecltd.github.io/barge-monitor/

Everything is fictional: the canal, its places and the weather.

## Layout

| Path | What |
|---|---|
| `srd-barge.md` | Software Requirements Document, Version 3.2 |
| `contracts/` | Masters for the seam: `openapi.json` (generated by FastAPI, committed, checked by a test), `profile.json` and its JSON Schema, JSON Schemas for discovery shapes, the SWE Common sensor record |
| `backend/barge/` | Python: world generator, barge, sensors, logger store, store adapter, Connected Systems server (FastAPI), analysis service, scoring, message tap |
| `backend/contract_suite/` | Contract tests run in CPython under uvicorn and in the browser through the relay (AT-02) |
| `backend/tests/` | pytest acceptance tests |
| `backend/independent/` | AT-16: OSHConnect-Python browses the server |
| `web/` | TypeScript and React: the shell (flowchart, controls, key, tour), the display client and its panels, the relay (Service Worker), the two Pyodide workers, Playwright tests |
| `scripts/build_history.py` | Pre-built history: the logger files for seeds 1–3 (SRD §13) |
| `docs/decisions-log.md` | Every decision taken while implementing, for review |
| `docs/adr/`, `docs/findings/` | Decision records and measured findings |

## Run it locally

```sh
pip install -r backend/requirements-dev.txt
(cd backend && python -m pytest -q)                      # Python tests, about 20 s

python scripts/build_history.py --days 7 .cache/history 1 2 3   # one week, as the tests use
cd web
npm ci
npm run pyodide          # Pyodide 0.29.5 and packages into ../.cache (once)
npm run build            # generates TypeScript types from contracts/, packs the Python
npm run site             # assembles ../dist-site/{demo,pyodide,history}
npm run serve            # http://localhost:8080/demo/
npm run e2e              # Playwright tests
```

The published site uses `--days 28` (four weeks). `?seed=N` with a seed that has
no pre-built history generates its history in the browser instead.

The server also runs under an ordinary ASGI server:
`cd backend && python -c "import uvicorn; from barge.runtime import Runtime; from barge.api import create_app; uvicorn.run(create_app(Runtime(pregen_days=1)))"`.
